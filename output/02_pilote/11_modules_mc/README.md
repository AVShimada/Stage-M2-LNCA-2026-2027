# 11_modules_mc

Modules du graphe des liens à partir de la MC individuelle.

Voir WORKFLOW_1000BRAINS.md pour la méthode et les prérequis. Chaque exécution conserve ses entrées et ses paramètres dans manifest.json, ses valeurs dans data/ et ses figures dans figures/.

Exemple du premier lancement : `/home/aurelio/.venvs/lnca-1000brains/bin/python script/pipeline.py modules-mc --config output/04_exports/20261124T160858261377Z/pilote.json --run 20261124T160858261377Z`
