# 09_distance

FC moyenne selon la distance entre les centres des régions.

Voir WORKFLOW_1000BRAINS.md pour la méthode et les prérequis. Chaque exécution conserve ses entrées et ses paramètres dans manifest.json, ses valeurs dans data/ et ses figures dans figures/.

Exemple du premier lancement : `/home/aurelio/.venvs/lnca-1000brains/bin/python script/pipeline.py distance --config /home/aurelio/Server/Aurelio_Stage_M2/output/04_exports/20261124T160858261377Z/pilote.json --run 20261124T160858261377Z`
