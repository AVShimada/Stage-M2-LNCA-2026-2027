# 06_descriptifs

Descriptifs des sujets avec un second scan

Voir WORKFLOW_1000BRAINS.md pour la méthode et les prérequis. Chaque exécution conserve ses entrées et ses paramètres dans manifest.json, ses valeurs dans data/ et ses figures dans figures/.

Exemple du premier lancement : `/home/aurelio/.venvs/lnca-1000brains/bin/python script/decrire_second_scan.py --population filtree --cohorte-run 20261124T160858261377Z --scores-run 20261124T160858261377Z --run 20261124T160858261377Z`
