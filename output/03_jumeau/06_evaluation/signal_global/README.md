# signal_global

Signal global et écarts de FC

Voir WORKFLOW_1000BRAINS.md pour la méthode et les prérequis. Chaque exécution conserve ses entrées et ses paramètres dans manifest.json, ses valeurs dans data/ et ses figures dans figures/.

Exemple du premier lancement : `/home/aurelio/.venvs/lnca-1000brains/bin/python script/audits/signal_global.py --pilote 20261124T160858261377Z --jumeau 20261125T142342234738Z`
